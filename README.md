# ปฏิทินเข้างาน

ปฏิทินเข้างานสำหรับพนักงานปั๊มน้ำมัน อ่านไฟล์ Google Timeline ในเครื่อง แล้วสรุปกะเช้า กะบ่าย และตำแหน่ง Support

ข้อมูลอยู่บนเครื่องเท่านั้น ไม่ได้ถูกส่งขึ้นเซิร์ฟเวอร์

## เปิดเป็นเว็บสาธารณะบน GitHub Pages

1. อัปโหลดโปรเจกต์นี้ขึ้น GitHub แบบ public
2. ที่แท็บ Settings → Pages → Build and deployment ให้เลือก Source เป็น **GitHub Actions**
3. พอ push ขึ้นสาขา `main` ระบบจะสร้างเว็บให้เอง
4. เปิดลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อคลัง>/` ด้วย Chrome บนมือถือ
5. กด **ติดตั้ง** ในแอป หรือเมนู Chrome แล้วเลือกติดตั้ง ไอคอนปฏิทินจะอยู่ที่หน้าจอหลัก
